# Quickstart: Maxitor shows events

1. Start the stand with `build_erd_events.py` and open a domain with a vocabulary: Events diagram, label "Vocabulary", two bands.
2. Open a domain without one: label "No vocabulary", one band.
3. Find methods of all five kinds joined to events.
4. Open an event's card: fields, methods, domains; follow a method.
5. Compare two versions differing by an event: added and removed marks, counts on the version button.
6. Open a document of version 1.2: no error.
