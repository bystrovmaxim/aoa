# Contract: UI

| Element | In Diff |
|---|---|
| Action, role | Green, amber, red and dashed, or faded; the sign `+ − ~` in the hover label |
| Link | Its own status's colour; removed dashed; unchanged faded |
| Button | `◷ A <name> → B <name>  +n −n ~n ▾`, or "no changes" |
| Stepper | Beside the button, as on the ERD; Shift + ↑ ↓ |
| Card, changed inside | Title, "The action is the same; its parts changed", groups, rows |
| Card, otherwise | As spec 038 |
| Panel | Domains; Changes in Diff; gear shift |

In One nothing differs from today but the panel, which replaces the domain legend.

Test ids stay: `diff-card`, `diff-row`; new `diff-part-group`.
