## About `@hpcc-js/wasm-graphviz`

This is the Graphviz build compiled to WebAssembly, which the viewer uses for graph
layout. It is distributed under the Apache License 2.0 — the same license as this
project, whose Sections 1 through 9 are byte for byte the text of the `LICENSE` file
that ships beside this notice.

The package supplies no copyright line of its own: its `LICENSE` is the standard
Apache text with the appendix left as the template `Copyright [yyyy] [name of
copyright owner]`, it ships no `NOTICE` file, and its published code carries no
banner. It declares its publisher as `hpcc-systems`. This page therefore records what
the package itself states, and does not invent a holder that no file in it names.

## Scope

This list covers the runtime dependencies of the client bundle, as declared in
`packages/maxitor/front/client/package.json` and resolved in its lockfile. It is **not a
complete inventory**: the bundle also contains transitive dependencies of these
components, and a complete list would have to be generated by scanning the built
assets against the lockfile. Development dependencies are excluded — they build the
bundle and are not redistributed inside it.
